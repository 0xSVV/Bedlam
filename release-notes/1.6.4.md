Bedlam 1.6.4 fixes a crash on launch that a damaged settings file caused.

**Fixes**

- A settings file that was damaged, for example by a sudden reboot, made Bedlam close on every launch until it was reinstalled. Bedlam now replaces such a file and starts; the log says which file it was. Profiles are stored elsewhere and are not affected.
- Crash reports name the real classes and methods. The code was never secret, so it is no longer obfuscated.

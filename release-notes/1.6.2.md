Bedlam 1.6.2 lets you check for updates in Settings and asks before switching profiles while the tunnel is up.

**Updates**

- Settings has a Check for updates row. It names a newer version when one is out, and tapping it opens the update screen.
- If you tap Not now for the same version three times, Bedlam stops offering it when the app starts. You can still install it from Settings.

**Profiles**

- Tapping another profile while the tunnel is up no longer changes the selection silently. The connect button splits into confirm and cancel; confirming reconnects through the new profile, and cancel keeps the current one.

**Fixes**

- An MTU or routing change made while the tunnel was reconnecting was lost until you connected again. It now applies at once.

Bedlam 1.6.3 keeps the DNS presets answering when your server cannot reach the provider by name, and shows crashes and tunnel events in the log.

**DNS**

- The Cloudflare and Google presets for DNS over TLS and DNS over HTTPS fall back to the provider's IPv4 addresses when the hostname endpoint fails, so a server with broken IPv6 no longer loses DNS.
- With IPv6 set to Disabled, name lookups return no IPv6 addresses, so apps connect over IPv4 at once instead of retrying.

**Logs**

- The log now includes app events: the last process exit, tunnel start and stop, network changes, a revoked tunnel and the previous crash.
- When Bedlam crashes, a notification offers to share the crash report.

**Other changes**

- If the installed build has no native library for the device, Bedlam says which build to install instead of closing at once.
- A notification says when another VPN app takes over the tunnel.
- The universal APK installs over any per-ABI build of the same release.

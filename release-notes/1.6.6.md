This update brings the Hysteria core to 2.13.0 and sing-tun to 0.9.6. It also improves DNS handling, network changes, and route-source refreshes.

**DNS and routing**

- DNS response caching is enabled by default. Turn it off in Routing settings without restarting the tunnel.
- Server bootstrap and enabled domain bypass rules use the selected network's system DNS over protected UDP. Other DNS queries continue to use the configured Remote DNS provider.
- Domain bypass rules match exact DNS names. Validated A/AAAA answers use short-lived protected TCP/UDP routes. CIDR and ASN rules remain IP-based, and apps excluded from the VPN continue to use Android DNS.
- Cloudflare and Google DoT/DoH presets use hostname endpoints without generated numeric fallbacks. DNS failures do not silently switch providers.
- Network handoffs refresh the DNS resolver snapshot and routing state. IPv6 modes, stale DNS work, and transient route refresh failures receive more consistent handling.

**Direct DNS support**

Direct DNS currently supports the network's system resolvers over UDP. The provider, custom-server, and alternate transport controls remain unavailable until their protected runtime support is implemented.

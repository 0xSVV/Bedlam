Bedlam finds addresses faster, holds the connection longer, uses less battery, and lets you set the MTU.

**Pages that showed no images**

- Bedlam opened a new connection to the DNS server for each lookup. Bedlam now keeps a small number of connections and uses them again. A page with many image hosts now gets all its addresses in one group of queries.
- Bedlam answers a name that it already knows immediately. Before, that answer waited behind the lookups that were not complete.
- Bedlam allows 64 lookups at the same time. The limit was 16.
- Bedlam now decreases the lifetime of an answer that it kept. Before, Bedlam gave the answer its full lifetime again on each use. Apps thus kept old addresses too long.

**Connection drops**

- The tunnel now waits 60 seconds before it decides that a silent path is dead. The limit was 30 seconds. A change between networks, or a short block, no longer stops the connection.
- Bedlam finds a dead tunnel in 30 seconds instead of 60.
- Your server must also allow 60 seconds. QUIC uses the shorter of the two limits. Set `quic.maxIdleTimeout` to `60s` or more in the server config.

**Battery**

- Bedlam sent a keepalive packet every 10 seconds. Bedlam now sends one every 25 seconds. The radio thus wakes up less frequently.
- Bedlam opened and closed a session through the tunnel every 60 seconds, even with the screen off. Bedlam no longer opens that session.
- DNS over HTTP/3 held its own connection open with a second keepalive. That connection now closes when it is not in use.

**MTU**

- Settings → Routing has a new MTU row. Leave the row empty to use Auto. Auto sets 1280 bytes.
- You can set a value from 1280 to 9000 bytes. Bedlam cannot use a smaller value than 1280. The tunnel interface always holds an IPv6 address, and IPv6 does not allow less.

**DNS**

- The Transport row has a new choice: DNS over QUIC (RFC 9250). To use it, set the DNS mode to Custom. Cloudflare and Google do not publish a DNS over QUIC address.
- Write a server as `dns.adguard-dns.com`, `quic://dns.nextdns.io`, or with a port. Bedlam uses port 853 by default.
- Bedlam uses DNS over TLS instead if your server does not relay UDP. Bedlam also uses DNS over TLS if it cannot use any of your servers.

**Google Play Protect**

Google Play Protect can tell you that Bedlam is harmful. Play Protect looks for these three things together:

- Bedlam is not on Google Play.
- Bedlam downloads its own updates.
- Bedlam can install those updates.

Bedlam does all three. To check the file that you installed, compare its signature with this value:

`53dc7856de56620d6428a344662ee0b3c3bf5d09faa16312534945044ba2d109`

Faster lookups, a steadier tunnel, less battery, and a settable MTU.

**Pages that showed no images**

- Bedlam opened a new connection to the DNS server for each lookup. It now keeps a small pool and reuses it. A page with many image hosts resolves them in one round of queries.
- A cached name is now answered at once. Before, it waited behind the lookups that were still in progress.
- Bedlam allows 64 lookups at the same time. The limit was 16.
- A cached answer now counts its time down. Before, Bedlam gave the answer its full lifetime again on each use, so apps held old addresses too long.

**Connection drops**

- The tunnel now waits 60 seconds before it treats a silent path as dead. The limit was 30 seconds. A handover between networks, or a short block, no longer ends the connection.
- Bedlam finds a dead tunnel in 30 seconds instead of 60.
- Your server must also allow 60 seconds. QUIC uses the shorter of the two limits. Set `quic.maxIdleTimeout` to `60s` or more in the server config.

**Battery**

- Bedlam sent a keepalive packet every 10 seconds. It now sends one every 25 seconds. This wakes the radio much less.
- Bedlam opened and closed a session through the tunnel every 60 seconds, even with the screen off. It no longer does this.
- DNS over HTTP/3 held its own connection open with a second keepalive. That connection now closes when it is not in use.

**MTU**

- Settings → Routing has a new MTU row. Leave it empty for Auto, which uses 1280 bytes.
- You can set 1280 to 9000 bytes. Bedlam cannot go below 1280, because the tunnel interface always holds an IPv6 address and IPv6 does not allow less.

**DNS**

- The Transport row has a new choice: DNS over QUIC (RFC 9250). Choose Custom for the DNS mode to use it, because Cloudflare and Google do not publish a DNS over QUIC address.
- Write a server as `dns.adguard-dns.com`, `quic://dns.nextdns.io`, or with a port. Bedlam uses port 853 by default.
- Bedlam uses DNS over TLS instead if your server does not relay UDP.

**Google Play Protect**

Google Play Protect can call Bedlam harmful. Bedlam is not on Google Play, it downloads its own updates, and it can install them, and that is the behaviour Play Protect looks for. To check what you installed, compare the signature of the APK with this value:

`53dc7856de56620d6428a344662ee0b3c3bf5d09faa16312534945044ba2d109`

Bedlam 1.7.1 improves latency checks and updates the Hysteria core to 2.14.0.

**Connection and privacy**

- Latency checks now measure an HTTPS request through the selected profile. Results refresh after reconnecting, with clearer timeout and connection errors.
- Blocked Android system proxy connections from borrowing the VPN tunnel across apps and profiles.
- Restored the default QUIC idle timeout to 30 seconds and keepalive interval to 10 seconds. Custom values are preserved.

**DNS**

- Added DNS over TLS for OpenDNS in both Direct and Remote DNS.
- Connection logs now show the active Direct and Remote DNS transports and servers.

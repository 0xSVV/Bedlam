Rename profiles, pick how DNS travels, import a link or a JSON on purpose — plus safer in-app updates, and the app keeps your password off the screen and off the clipboard preview.

**Profiles**

- You can rename a profile. Open it, tap Edit, and change the name at the top of the editor. The dashboard and the notification title follow the new name.
- Copy config now includes the profile name, so a copied profile keeps its name when you import it again.

**DNS**

- The DNS section now has a Transport choice: UDP, TCP, DNS over TLS, DNS over HTTPS, or DNS over HTTP/3. Every transport runs through the tunnel; the Cloudflare and Google presets work with all of them.
- Custom servers accept IPv6 (`2620:fe::fe`, `[2620:fe::fe]:53`), host names for DNS over TLS (`dns.quad9.net`), and URLs or bare hosts for DNS over HTTPS and HTTP/3 (`https://dns.quad9.net/dns-query`). Entries Bedlam cannot use are pointed out under the field.
- Several servers are tried in order, and Bedlam sticks with the one that answers.
- Bedlam now answers DNS itself on the tunnel interface (172.19.0.2 and fdfe:dcba:9876::2) and forwards each lookup with the transport you chose. If you relied on Android's automatic Private DNS through the tunnel, pick DNS over TLS or DNS over HTTPS under Settings → Routing → DNS.
- The System DNS note now says what actually happens: your network's resolvers are queried through the tunnel, and they still see every lookup.

**Import**

- The + button opens an Import sheet with a Link / JSON switch, so Bedlam parses exactly what you meant. The sheet starts with whatever is on the clipboard, and a Paste button refills it.
- You can name a profile while importing it.
- Pasting an official Hysteria client config no longer produces a puzzling error; Bedlam explains that it is not a Bedlam profile.
- Tapping a `hysteria2://` or `hy2://` link in another app opens Bedlam with the link ready to import.

**Updates**

- Bedlam now compares the signature of an update with the signature of your installed app. If the two do not agree, Bedlam refuses the update and tells you why.
- Android can block Bedlam from installing apps. Bedlam now opens the correct settings page instead of failing with a number.
- Bedlam downloads an update only from GitHub, and only over an encrypted connection.
- Bedlam stops a download that is larger than the release says.
- Bedlam deletes the downloaded file after it installs the update.
- Bedlam checked for updates each time you turned the phone. Bedlam now checks at most one time every six hours.
- The back gesture closed the app on the update screen. The back gesture now returns you to the dashboard.
- Bedlam abandons a failed install correctly, so later installs still start.

**Privacy**

- The auth password is now hidden in the profile editor. Use the Show button to read it.
- When you copy a profile, Bedlam marks the clipboard content as sensitive, so Android hides it in the clipboard preview.
- Bedlam now refuses all unencrypted network connections.

**Speed test**

- The speed test showed a browser error page when it could not load. It now shows a message and a Retry button.
- The speed test stays on its own website and has no access to files on the phone.
- The speed test now stops when you leave the screen. Before, it continued in the background.

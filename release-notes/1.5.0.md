Rename a profile, choose how DNS travels, and import a link or a JSON on purpose.

**Profiles**

- You can rename a profile. Open it, tap Edit, then change the name. The dashboard and the notification follow the new name.
- Copy config now writes the profile name, so an imported copy keeps it.

**DNS**

- The DNS section has a new Transport row: UDP, TCP, DNS over TLS, DNS over HTTPS, or DNS over HTTP/3. All of them go through the tunnel, and the Cloudflare and Google presets work with each one.
- Custom servers accept IPv6 (`[2620:fe::fe]:53`), host names for DNS over TLS (`dns.quad9.net`), and URLs for DNS over HTTPS and HTTP/3 (`https://dns.quad9.net/dns-query`). Bedlam marks an entry it cannot use.
- Bedlam tries your servers in order, then keeps the one that answers.
- Bedlam now answers DNS on the tunnel interface and sends each lookup with the transport you chose. An app that ignores the system resolver gets the same treatment, so it can no longer send your lookups in the clear. If you used Android Private DNS through the tunnel, choose DNS over TLS or DNS over HTTPS in Settings → Routing → DNS.
- A DNS server on your own network works as before. Bedlam gives it to Android, and it stays on your network.
- The System DNS note now tells you what happens. Bedlam asks your network's resolvers through the tunnel, and they still see every lookup.

**Import**

- The + button opens an Import sheet with a Link and JSON switch. The sheet starts with the clipboard text, and the Paste button fills it again.
- You can name a profile while you import it.
- Bedlam refuses a profile you already saved, and tells you the name it saved it under.
- Bedlam now explains that an official Hysteria client config is not a Bedlam profile.
- Tap a `hysteria2://` or `hy2://` link in another app to open Bedlam with the link ready.

**Updates**

- Bedlam compares the signature of an update with the signature of your installed app. If the two disagree, Bedlam refuses the update and tells you why.
- Android can stop Bedlam from installing apps. Bedlam now opens the correct settings page instead of showing a number.
- Bedlam downloads an update only from GitHub, and only over an encrypted connection.
- Bedlam stops a download that is larger than the release says.
- Bedlam deletes the file after it installs the update.
- Bedlam checked for updates each time you turned on the phone. Bedlam now checks once every six hours.
- The back gesture closed the app on the update screen. It now returns you to the dashboard.
- Bedlam ends a failed install correctly, so later installs still start.

**Privacy**

- Bedlam hides the auth password in the profile editor. Tap Show to read it.
- Bedlam marks a copied profile as sensitive, so Android hides it in the clipboard preview.
- Bedlam refuses all unencrypted network connections.

**Speed test**

- The speed test showed a browser error page when it could not load. It now shows a message and a Retry button.
- The speed test stays on its own website, and cannot read files on the phone.
- The speed test now stops when you leave the screen. Before, it continued in the background.

Bedlam 1.7.0 adds Direct DNS providers and improves imports and profile editing.

**DNS**

- Direct DNS now supports UDP, TCP, DNS over TLS and DNS over HTTPS. Encrypted presets can resolve the Hysteria server without relying on your network's DNS.
- OpenDNS and AdGuard are available for both Direct and Remote DNS. AdGuard filters ads, trackers and phishing domains.
- Direct DNS changes apply while connected. The IPv6 Bypass only setting now explains which DNS resolver it uses.

**Other changes**

- Long-pressing the Quick Settings tile opens Bedlam.
- Link and JSON import tabs keep separate drafts and errors.
- The profile editor stays above the keyboard, and its toolbar no longer covers content in landscape.
- Home explains when you need to select a profile. Denying VPN permission now shows a message.
- Profile links with escaped characters work on Android 10–12L.
